# 首页

- 路由: `/`
- 状态: 骨架（create-next-app 模板 + demo 入口）
- 版本: 0.1

## 目标

- 项目入口页：展示项目身份，引导用户进入组件演示页 `/demo`。

## 非目标

- 不是营销 landing：无 hero 图片、无卖点叙事、无 SEO 结构。
- 不是多页导航的中枢：当前没有站点地图。

## 用户与场景

- 开发者（或协作者）打开项目首页 → 一键进入组件演示，快速确认组件库状态。

## 页面与路由

| 路由 | 说明 |
|---|---|
| `/` | 首页，细则见 [app/PAGE.md](../../app/PAGE.md) |

## 功能需求

### 正常流程

- 开发者打开首页，看到项目身份、模板说明和页面入口。
- 保留 create-next-app 模板结构（logo、标题、说明、外部链接）。
- 按钮区含 "View Components Demo"（Link 包 Button）跳转 `/demo`，这是进入功能页的唯一入口，必须保留。

### 异常与边界

- 无数据请求、无状态、无异步。

## 验收标准

- `/` 200 渲染，无 console 错误；默认亮色显示正常。
- "View Components Demo" 可跳转到 `/demo`。
- 验证三件套通过（docs/verification.md）。

## 数据与接口

- 无。

## 风险与依赖

- 页面仍是模板文案（"To get started, edit page.tsx"）；真实产品定位确定后需整页重写。
